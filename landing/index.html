Feature #2 ACTIVE

Invisible in Dock / Taskbar

Windows Taskbar aur macOS Dock par koi application icon ya window handle show nahi hota. Rev runs silently as an undetectable background service with zero visual desktop trace.

Process name automatically masquerades as a standard system process (e.g. Windows Audio Driver / CoreAudio Helper). Agar interviewer Task Manager khulwa kar screen check kare, tab bhi zero suspicion.
